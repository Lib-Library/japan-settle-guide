## 내린 결정

- 기한 계산값 `due`는 `deadline` 문장의 숫자만 쓴다. 종류: arrival(정확) / estimate(예상, 원래 기준 문장 함께 표시) / yearly / none(날짜 안 붙임)
- 날짜 근거가 없는 항목은 시기별 **권장 시기**(입국 전 0일, 2주 +14, 3개월 +90, 1년 +365)에 놓고 [권장] 표시 + "법정 기한 아님"
- 날짜 없음(none): 연말정산, 은행 신고사항 변경, 주민세
- 국제운전면허: 상륙일 포함 계산이라 1년에서 하루 뺌(`months: 12, days: -1`) — **경찰청 출처로 확인 필요**

1. 홈 — 오늘의 할 일(가장 급한 마감, 이번 주 할 일, 세로 시기 흐름, 도구 바로가기)
2. 시기 페이지 — 권장 순서 단계로 카드 묶기, 장소·D-day 칩
3. 할 일 페이지 — 내 마감일, 어디서/언제까지 요약, 준비물 체크, 창구에서 보여주기 버튼
4. 창구용 화면 — 일본어 큰 글씨 + 준비물
5. 내 일정 — 날짜 띠, 선택한 날 할 일, 다가오는 일

추천 구현 순서: 공통 아이콘·칩 → 홈 → 시기 페이지 → 할 일 페이지(창구 화면) → 내 일정
