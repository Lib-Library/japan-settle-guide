입사가 정해지면 회사가 COE(재류자격인정증명서)를 신청하는 동안, 본인은 **한국 쪽 정리**를 시작하세요. 병역·연금·건강보험은 개인 상황에 따라 답이 달라서 기관에 문의할 시간이 필요합니다.

권장 순서: (해당자) 병무청 허가 확인 → COE·비자 → 한국 주민등록·연금·건강보험 처리 → 이삿짐 → 입국·재류카드 수령

배경 설명은 [입국 전 준비 가이드](/topics/pre-arrival/)에 정리했습니다.
