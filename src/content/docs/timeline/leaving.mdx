일본을 떠날 때는 **출국 전에 일본에서 끝내야 하는 일**이 많습니다. 출국한 뒤에는 처리하기 어렵거나(전출신고, 주민세, 계좌 해지) 기한이 정해진 일(연금 탈퇴일시금 2년)이 있으니, 귀국이 정해지면 바로 이 목록을 확인하세요.

권장 순서: 집 해약 예고(보통 1~2개월 전) → 공과금·휴대폰·인터넷 해지 예약 → 주민세·세금 정리, 납세관리인 정하기 → 전출신고 → 은행 계좌 해지 → 출국(재류카드 반납) → 한국에서 귀국 신고 → 탈퇴일시금 청구
