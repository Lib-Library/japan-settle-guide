## 이 가이드를 쓰는 방법

1. 지금 시기를 골라 체크리스트를 위에서부터 차례대로 확인하세요.
2. 항목을 누르면 **어디서 / 언제까지 / 준비물 / 흔한 실수**가 나옵니다.
3. 일본어 원어는 `転入届(덴뉴토도케)`처럼 한글 독음과 함께 적었습니다. 창구에서 그대로 보여 주거나 읽으면 됩니다.
4. 노란 <span class="verify-badge">확인 필요</span> 표시는 아직 공식 출처로 확인하지 못한 내용입니다. 반드시 해당 기관에 직접 확인하세요.

제도와 금액은 바뀔 수 있습니다. 이 사이트는 일반적인 안내이며, 최종 판단은 각 페이지에 연결한 공식 기관 안내를 따르세요. 자세한 원칙은 [이 사이트에 대해](/about/)를 참고하세요.
